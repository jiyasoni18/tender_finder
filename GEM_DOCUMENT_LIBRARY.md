> ⚠️ **Never substitute an approximate document.** If a tender demands something the library does not
> actually hold, do **not** map the nearest-looking file. Write it as **`MANUAL REQUIREMENT — not in
> library`** and state plainly what has to be arranged. A wrong document in an upload slot is worse
> than an empty one, because it reads as a genuine attempt to comply and gets the bid rejected on
> inspection rather than on a checklist.
>
> "Retitle this BSNL template for ITI" or "adapt this Maharashtra Telecom proforma" is a **manual
> requirement**, not a mapping — the file is a starting point, not the deliverable. Say so.

### The three actions — use exactly these words

Every required document gets one of three labels. Never blur them.

| Label | When | How to write it |
|---|---|---|
| **MAP** | An exact file exists in the library | `MAP: KYC DOCS/ARKONIK GST.pdf` |
| **CREATE** | An **undertaking, declaration, certificate-by-us, compliance statement or annexure** — anything that is just our own words on our letterhead. We can write it ourselves; nothing external is needed. | `CREATE a declaration from ChatGPT — undertaking on company letterhead indemnifying ITI against claims, penalties, statutory charges, liquidated damages and legal expenses` |
| **MANUAL REQUIREMENT** | A document only an **outside body** can issue — ISO certification, a licence, a CA certificate, a bank instrument, a client's completion certificate | `MANUAL REQUIREMENT — not in library. ISO 9001:2015, issued by a certification body` |

The test between CREATE and MANUAL REQUIREMENT: **who signs it?** If we sign it, it's CREATE — write
it fresh. If a third party signs it (auditor, certifying body, government office, bank, client),
it's a MANUAL REQUIREMENT and it has a lead time.

Write CREATE items as a plain instruction naming the buyer and exactly what the undertaking must say,
so the declaration can be drafted straight from that line without reopening the tender.

**GeM "Document required from seller" slots.** Where a slot reads *"(Requested in ATC)"*, open the
ATC and check whether it actually names a document for that slot. If it names one, the slot is
mandatory and you upload what it names. If the ATC names nothing — as with **"Additional Doc 1"**,
where the phrase "Additional Doc" typically appears nowhere in the ATC at all — **do not list it as a
mandatory document**. Use the slot as a catch-all for ATC checklist items that have no slot of their own.

**Where the real list lives.** The GeM bid page shows only 3–4 upload slots. The buyer's uploaded ATC
usually carries the actual requirement list, often headed *"Checklist of documents/information to be
submitted"*. Always read the ATC before deciding what a tender needs.

### The "detailed write-up" requirement

Most ATCs ask somewhere for a narrative write-up — *"areas of expertise and the past experience of
executing various projects and business endeavors accomplished, showcasing their strengths and
challenges"*. This is a **CREATE**, and **the experience is what goes in it**:

1. Open `KYC DOCS/arkonik EXPERIENCE.pdf` and read the actual projects, clients and values off it
   (it is scanned, so this has to be done by eye).
2. Write the narrative from those real projects — expertise areas, what was executed, for whom,
   the strengths demonstrated and the challenges met.
3. Attach `arkonik EXPERIENCE.pdf` itself as the supporting evidence behind the narrative.

Never write this section from generic capability language. It has to trace back to the certificates,
because the buyer can and does cross-check the two against each other.

## MANUAL REQUIREMENTS — not in the library

These are **not held**. When a tender asks for any of them, write `MANUAL REQUIREMENT — not in library`
against that line. Do not map a substitute.

| Missing document | Why it matters | How to obtain |
|---|---|---|
| **ISO 9001:2015 certificate** | Demanded by quality-certification clauses (e.g. ITI ATC 6(i)g). | Certification body audit — lead time of weeks, not days. Plan ahead of the bid. |
| **ISO 27001 certificate** | Same clause. | As above. |
| **Security Certificate** | Same clause. | Depends what the buyer means — clarify via the Representation window before assuming. |
| **Labour Licence (actual)** | Only an *undertaking to obtain* one (#56) exists — not the licence itself. | Labour Commissioner, under the Contract Labour (R&A) Act 1970. |
| **CA Net Worth certificate** | #14 certifies turnover only. Tenders routinely ask for both together. | N J Salot & Associates — same CA who issued the turnover certificate. |
| **NSIC registration** | Some ATCs require NSIC *alongside* MSME for EMD exemption. Udyam alone may not satisfy them. | NSIC — check before relying on an EMD exemption. |

### Annexure formats supplied by the buyer

Where an ATC supplies its own Annexure format (Annexure-I, II, III … ), the buyer's format **must** be
used. That is a **CREATE** — fill their format with our data. Name which library file supplies the
content, but never offer our own version of the annexure in place of theirs.
